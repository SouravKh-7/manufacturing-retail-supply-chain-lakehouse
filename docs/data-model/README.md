# Data-model contract

Proposed entities include supplier, product, plant, warehouse, store, customer, purchase order and line, receipt, manufacturing order and output, inventory movement and snapshot, retail order and line, sale, and return. Each implemented table must document grain, key, change behavior, event time, arrival time, source lineage, and history policy.
